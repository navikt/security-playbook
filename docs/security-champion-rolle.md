En Security Champion hjelper teamet med å ha sikkerhet med i det daglige arbeidet. Du trenger ikke være sikkerhetsekspert, men bør være interessert i sikkerhet og dele det du lærer med teamet.

Teamet har fortsatt det samlede ansvaret for sikkerheten. Du støtter teamet som pådriver og kontaktperson, men står ikke alene med ansvaret.

## Dette gjør du i rollen

- Vær teamets kontaktperson for sikkerhetsspørsmål.
- Følg med på [#security-champion](https://nav-it.slack.com/archives/CN8N938K1) og bidra i nettverket.
- Lær om relevante sikkerhetstemaer, og del kunnskapen med teamet.

## Meld deg inn

Registrer deg i [Security Champion Stats](http://securitychampion.ansatt.nav.no/). Innmelding skjer i appen, ikke i Teamkatalogen.

Hvis du allerede var Security Champion, må du også registrere deg på nytt. Tidligere innmeldinger ble ikke overført. Du kan når som helst melde deg ut.

## Security Champion-programmet

Programmet gir poeng for aktivitet i fellesskapet. Poeng gir nivåer, og nullstilles hvert år.

Du får poeng når du deltar på meetups og workshops, registrert via Delta, er aktiv på Slack og bidrar til playbooken. Appen får flere funksjoner og måter å samle poeng på etter hvert.

Følg med på [arrangementene](/docs/events/) og i [#security-champion](https://nav-it.slack.com/archives/CN8N938K1) for informasjon om aktiviteter.

## Kom i gang i teamet

Velg oppgaver som passer for teamet ditt. Du trenger ikke gjøre alt på én gang.

- Gå gjennom varsler for sårbarheter i avhengigheter og egen kode. Sjekk at Dependabot, Code Scanning og Secret Scanning er aktivert, og se teamets [sikkerhetsoversikt på GitHub](https://github.com/orgs/navikt/security/coverage).
- Les om [sikkerhet i tredjepartskode](/docs/sikker-utvikling/tredjepartskode) og temaene under [Sikker utvikling i Nav IT](/docs/sikker-utvikling).
- Undersøk hva teamets apper logger, og se etter logger som mangler eller inneholder for mye informasjon. Se rådene om [logging](/docs/sikker-utvikling/logging).
- Finn tjenester og GitHub-repoer teamet ikke lenger bruker. Slå av gamle tjenester og arkiver repoer som er forlatt.
- Del en forbedring i [Security Playbook på GitHub](https://github.com/navikt/security-playbook). Du kan også lære sammen med andre ved å delta på meetups og workshops eller ta en kaffeprat med en annen Security Champion.
- Finn kurs, bøker og øvingsoppgaver blant [sikkerhetsressursene i playbooken](/docs/lenker). Du kan også prøve CTF-oppgaver hos [PicoCTF](https://picoctf.org/) eller [TryHackMe](https://tryhackme.com/).

## Vanlige spørsmål

### Må jeg være sikkerhetsekspert?

Nei. Interesse for sikkerhet er nok til å begynne. Du kan bygge kompetansen over tid sammen med teamet og nettverket.

### Kan konsulenter bli Security Champion?

Ja. Rollen kan passe for både fast ansatte og konsulenter. Teamet bør velge den som ønsker å ta på seg oppgaven.

### Kan et team ha flere Security Champions?

Ja, hvis det passer for teamet. Sikkerheten er uansett teamets felles ansvar.
